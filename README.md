# গল্পে শিখি Vocabulary! — React JS Landing Page

## প্রজেক্ট স্ট্রাকচার
- `index.html` — পেজ টাইটেল, ফন্ট (Hind Siliguri ও Plus Jakarta Sans) এবং ফ্যাভিকন
- `src/App.jsx` — পুরো ল্যান্ডিং পেজের React কোড (বিকাশ নম্বর, হোয়াটসঅ্যাপ ও গল্পের ডেটা এখানেই আছে)
- `src/index.css` — Tailwind CSS স্টাইল
- `public/media/` — ভোকাব হিরো লোগো, হিরো কভার, পিডিএফ প্রিভিউ এবং প্রোমো ভিডিও

## VS Code-এ রান করার নিয়ম
১. Node.js (LTS) ইনস্টল করা থাকতে হবে (https://nodejs.org)
২. ফোল্ডারটি আনজিপ করে VS Code-এ ওপেন করুন (File -> Open Folder)
৩. VS Code-এ টার্মিনাল খুলুন (`Ctrl + ~`) এবং নিচের কমান্ডগুলো চালান:
```bash
npm install
npm run dev
```
৪. টার্মিনালে পাওয়া `http://localhost:5173` লিংকে ক্লিক করে ব্রাউজারে দেখুন।

## Vercel-এ ফ্রি হোস্টিং (সবচেয়ে সহজ)
১. GitHub-এ নতুন একটি রিপোজিটরি খুলে এই ফোল্ডারের সব ফাইল আপলোড করুন।
২. https://vercel.com এ GitHub দিয়ে লগইন করুন।
৩. **Add New -> Project** এ ক্লিক করে আপনার রিপোজিটরি সিলেক্ট করুন।
৪. **Deploy** বাটনে ক্লিক করলেই ১ মিনিটে আপনার ফ্রি লাইভ ওয়েবসাইট তৈরি হয়ে যাবে!
